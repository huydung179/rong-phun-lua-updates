# Rồng phun lửa — bản phát hành

App Android cho trẻ luyện phát âm: nói **"aaa"** → phun lửa 🔥, nói **"ôô"** → đeo kính phân tích 🔎 (camera trước, xử lý ngay trên máy, không gửi hình / tiếng đi đâu).

**Tải APK mới nhất:** https://github.com/huydung179/rong-phun-lua-updates/releases/latest/download/rong-phun-lua.apk

Cài một lần (cho phép "cài đặt từ nguồn không xác định"). Sau đó app tự cập nhật khi mở, ở bất kỳ đâu có Internet.

Repo này chỉ chứa bản phát hành (APK + gói cập nhật trong app + `version.json`), do script build đăng tự động.
